# Règles de confidentialité – LMF Robot

LMF Robot est l'outil personnel qu'utilise Le Média Français (lemediafrancais.fr) pour publier ses propres vidéos sur sa propre chaîne YouTube.

- **Données utilisées :** uniquement l'autorisation d'envoyer des vidéos sur la chaîne YouTube du Média Français et de lire la liste de ses propres vidéos (pour éviter les doublons).
- **Aucune donnée d'utilisateurs tiers** n'est collectée, stockée, vendue ou partagée.
- **Stockage :** le jeton d'accès est conservé de façon chiffrée dans les secrets GitHub du projet et n'est utilisé que pour publier nos vidéos.
- **Révocation :** l'accès peut être retiré à tout moment depuis https://myaccount.google.com/permissions.
- **Contact :** mathis@lemediafrancais.fr

L'utilisation des données reçues des API Google respecte les [Règles d'utilisation des données utilisateur des services d'API Google](https://developers.google.com/terms/api-services-user-data-policy), y compris les exigences d'utilisation limitée.
